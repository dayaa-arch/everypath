# 0002: モデル検査器は TLC だけにし、他のチェッカへの切替をやらない

日付: 2026-10-21
状態: 採用
影響する不変条件: なし（非目標「TLA+ 以外のチェッカ」の根拠。R-03 の「TLC が無くても動く」はそのまま）

## 背景

`SPEC.md` §16 フェーズ 3 に「Apalache など別のチェッカへの切替」がある。切替を見込むと、`src/core/tla/*` の生成・実行・パースを抽象化する層が要り、フェーズ 1 の設計に影響する。

## 決定

チェッカは TLC（`tla2tools.jar`）だけとする。`generate.ts`、`run.ts`、`parse.ts` は TLC の出力形式を直接扱い、他のチェッカ向けの抽象化を入れない。

## 捨てた案

- Apalache への切替を見込んだ抽象化。フェーズ 1 で使わないインターフェースを先に作ることになり、TLC 出力のパースという具体的な作業を遅らせる。
- Alloy 等の別の形式手法。アノテーション文法（`SPEC.md` §5.1）を TLA+ に落とせる範囲に限定した前提と合わない。

## 影響

`docs/REQUIREMENTS.md` の非目標に追加。`SPEC.md` §16 フェーズ 3 の「Apalache など別のチェッカへの切替」を削除する（確定時に直す）。

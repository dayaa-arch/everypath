# 0005: 0.1.0 は macOS と Linux だけを動作対象にする

日付: 2026-10-23
状態: 採用
影響する不変条件: なし（非目標「0.1.0 での Windows 対応」の根拠。要件定義書の未定「Windows 対応」を決めた）

## 背景

要件定義書は Windows を「非目標にしなかったので動作対象。CI の windows-latest で確認し、壊れていれば直すか非目標に移すかを作者が決める」としていた。CI（PR #24）で確かめると、Windows ではテストが 20 件失敗し、`serve` を子プロセスで動かすテストが止まった。主な原因は、Unix 前提のテストの作り（シェルスクリプトの偽の java、`/` 区切りのパスの比較）と、子プロセスの止め方である。製品そのものが Windows で使えるかは、その陰に隠れてまだ分からない。

## 決定

0.1.0 は macOS と Linux だけを動作対象にする。CI から Windows を外し、README に明記する。CRLF を LF にそろえてハッシュを取る修正は入れる（Windows の利用者が混ざったチームでも承認が保たれるため、次の版の Windows 対応の土台になる）。

## 捨てた案

- 公開前に Windows を直す。テストの作りの直しが中心だが、製品側の修正の範囲がまだ分からず、公開が遅れる。
- CI に Windows を残し、失敗しても止めない。`main` に失敗が常に出て、本当の退行と見分けにくくなる。

## 影響

`docs/REQUIREMENTS.md` の非目標に「0.1.0 での Windows 対応」を足し、未定から Windows の行を消す。`.github/workflows/ci.yml` の対象から `windows-latest` を外す。次の版で Windows に対応するときは、この決定を置き換える決定記録を書く。

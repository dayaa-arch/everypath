# 0001: UI・ドキュメント・指示文は日本語のみで書く

日付: 2026-10-21
状態: 採用
影響する不変条件: なし（非目標「英語化・多言語切替」の根拠）

## 背景

利用者に「OSS の不特定多数」を含めると決めた。OSS では英語 UI が通例だが、`SPEC.md` はボタン名、エッジラベル、生成する指示文まで日本語で設計されており、第一の利用者は作者本人である。

## 決定

ビューア、README、`skill/SKILL.md`、`templates/prompts/*.md` を日本語のみで書く。UI 文字列の辞書化や `config.lang` は持たない。

## 捨てた案

- 日本語 UI と英語 README の併用。README と画面の語が食い違い、スクリーンショットの説明が二重になる。
- 英語のみ。作者本人が日常で読む画面と指示文が英語になり、`SPEC.md` の日本語の状態名（ログイン、マイページ）との対応が取りにくい。
- 両言語切替。初期実装のコストが増え、フェーズ 1 の「思想の 3 要素が一周する」ことを遅らせる。

## 影響

`docs/REQUIREMENTS.md` の目的に利用者と言語を追記。非目標に「英語化・多言語切替」を追加する。英語化が必要になれば、この決定を置き換える決定記録を書く。
